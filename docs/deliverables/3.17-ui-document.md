# Tài liệu UI — 2026-11-08

Bản này mô tả luồng UI hiện đang chạy. Nguồn thật là code frontend:
`frontend/src/App.jsx`, `frontend/src/components/Layout.jsx`,
`frontend/src/pages/*`.

## Learner

- **Topbar**: `Dashboard`, `Assessments`, `History`, `Competency`, `Settings`
  (`LEARNER_LINKS` trong `Layout.jsx`).
- **Assessments**: chọn khái niệm, 3 band độ khó, số câu 1–20 (mặc định 5),
  nguồn `bank` / `ai`; `Bắt đầu` chỉ kích hoạt khi có chọn.
- **Exam**: hiển thị câu MCQ/SQL/essay; `Câu X / tối đa N`, hình dung việc
  `bank_mixed` bằng dòng notice: `Đã kết hợp câu SQL đã kiểm chứng từ ngân
  hàng với câu MCQ/tự luận do AI tạo.`
- **Evaluation**: `Nhận xét từng câu` và `Xu hướng qua các bài` dùng Chart.js;
  nếu không có AI thì hiển thị `Đánh giá dự phòng theo quy tắc`.
- **History**: nhìn nhận về tổng thể 0/1/3+ hay lịch sử; không set kiểu phân
  trang.

## Admin

- **Admin sidebar cố định 240px**; 5 mục `LEARNER_LINKS` như trên:
  `nav.cohort`, `supervisor.reviewTitle`, `nav.accounts`, `nav.bank`,
  `nav.system`.
- **System**: cấu hình flow type (`IMMEDIATE` / `HUMAN_VERIFIED`), Prompt
  Builder model path (nếu được cấu hình), status AI.

## Đồng bộ responsive

- Dùng theme Dark/Light selector; Chiều rộng 1480px tối đa; 360px có layout
  lại và không khựng scroll; dùng Tailwind.
