## Learner

- Tạo bài ôn luyện mới từ concept, độ khó, số câu, nguồn `bank` / `ai`.
- Xem tổng quan và nhận xét từng câu sau nộp bài.
- Nộp bài → AI chấm/đánh giá sơ bộ → quản trị viên duyệt → công bố; nhận xét từng câu từ Evaluator.

## Admin

- Xem tổng quan cohort.
- Duyệt bài / sửa điểm điều chỉnh (HUMAN_VERIFIED).
- Xem tài khoản, ngân hàng câu hỏi và khía cạnh CLO.
- Mở hệ thống (flow type, ai/prompt builder).
