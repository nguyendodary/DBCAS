  nguồn `bank`/`ai`.

- Evaluation page dùng Chart.js; khi không có AI, hiển thị
  `Đánh giá dự phòng theo quy tắc`.
- Admin: 5 mục như trước; `System` giúp cấu hình flow và Prompt Builder.
