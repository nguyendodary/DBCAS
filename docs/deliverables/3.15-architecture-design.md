# Thiết kế kiến trúc — 2026-11-07

Sản phẩm có ba khối chính:

- **Frontend React** (`frontend/src`): learner `Dashboard`, `Assessments`,
  `History`, `Competency`, `Settings`; admin 5 mục
  (`Cohort`, `Grading`, `Accounts`, `Bank & concepts/CLO`, `System`).
- **Backend FastAPI** (`backend/app`): học service, practice, questions,
  grading review, sandbox, semantic evaluator, Prompt Builder.
- **AI pipeline** (`docs/ai-pipeline.md`): Prompt Builder tạo prompt
  tiếng Việt, Evaluator chấm bằng AI; khi không cấu hình builder model thì
  builder dùng template fallback nhưng vẫn lưu `prompt_hash`.

## Quy tắc thiết kế

- `source=bank`: hoàn toàn ngân hàng validated.
- `source=ai`: AI chỉ tạo MCQ/essay; **SQL luôn từ ngân hàng validated**.
- Luồng công bố: một setting chung, `IMMEDIATE` hoặc `HUMAN_VERIFIED`.
- Exact-count guarantee 2.291.100/2.291.100.
- Diagnostics có reason code không chứa key hoặc content.
- Sandbox không mạng, statement timeout.
