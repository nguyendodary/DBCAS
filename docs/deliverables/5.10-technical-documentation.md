# Tài liệu kỹ thuật — vòng cuối

Ứng dụng local gồm React/Vite, FastAPI và PostgreSQL 17. Clone `develop2`,
chạy `npm start` khi chưa có `.env`; launcher tạo cấu hình, build, migrate,
seed và chờ readiness. Cổng mặc định: web 18080, API 18000, Mailpit 18025.
[Kịch bản demo](../demo/demo-script.md) có profile cô lập để giữ stack gốc.

## Nguồn chuẩn và lệnh

- `frontend/src/App.jsx`, `docs/inventory/frontend-routes.json`: route giao diện.
- `backend/app/main.py`, OpenAPI và `docs/inventory/`: API hiện tại.
- `db/schema.sql`, `db/migrations/`: schema/migration; đối chiếu
  [tài liệu CSDL](../database.md).
- `docker-compose.local.yml`, `scripts/local.mjs`: sáu service local;
  optional QA provider tạo tổng bảy định nghĩa.
- `npm run test:local`: launcher; `npm --prefix frontend run test:e2e`:
  browser DB/sandbox dùng một lần và kiểm tra ownership.
- `npm run test:qa`: provider HTTP giả local, không gọi dịch vụ trả phí.
- `backend/.venv/Scripts/python.exe backend/manage.py lint`, `build`, `test`:
  gate backend; chạy tuần tự với các suite Docker khác.
- `npm run docs:check`, `npm run docs:verify-word`, `npm run ui:contrast`:
  đối chiếu dự án, Word và token contrast.

## Hợp đồng hiện tại

Kế hoạch bài 1–20 câu đóng băng trước câu đầu. Câu trả lời có lưu nháp và
double-submit an toàn. Prompt Builder chỉ biến dữ liệu bài đã kết thúc thành
một prompt, không chấm; Evaluator nhận đúng prompt đó. Sau đánh giá sơ bộ,
quản trị viên kiểm tra, có thể sửa điểm kèm lý do rồi duyệt. Chỉ kết quả đã
công bố vào thống kê/xếp hạng.

Không có khóa vẫn chạy được bằng template/quy tắc có nhãn. Khóa chỉ đặt trong
cấu hình riêng, không log/commit. Vòng cuối hết ngân sách live theo
[sổ request](../qa/final-20261110/live-request-ledger.json); không dùng các
scratch wrapper cũ để gọi lại.

[W1–W8](../qa/final-20261110/README.md) ghi số gate thật, nguồn CI và giới hạn.
