- `backend/` FastAPI, PostgreSQL (test bằng docker compose), pytest.
- `scripts/` Node: `local.mjs` (stack), `browser-qa.mjs` (fake browser),

## Lệnh chính

- `npm start` khởi động stack frontend+backend (sau đó `npm run stop`).
- `npm ci`, `npm --prefix frontend ci` khi copy mới.
- `npm run test:local`, `npm --prefix frontend run test`, `npm run test:qa`.
- `backend/.venv/Scripts/python.exe backend/manage.py test` (backend full).
- `node scripts/browser-qa.mjs` (fake provider gate).
- `npm run diagrams:check`, `npm run inventory:check`.
